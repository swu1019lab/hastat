Documentation / hastat 2.0.0

From variants to haplotypes.

Extract gene haplotypes, compare population statistics, test phenotype associations and visualize the results.

Get started ↓Explore the figure gallery ↗Follow a complete example ↗
viewExtract haplotypes and estimate population statistics.statCompare phenotypes among haplotype groups.networkConstruct minimum spanning trees and networks.plotDraw distributions, networks and gene haplotypes.
01

Installation & quick start

Use Python 3.9 or later on Linux or macOS. Windows users can run hastat in WSL; the package uses pysam for VCF access.

Download the source

git clone https://github.com/swu1019lab/hastat.git
cd hastat

Option A: Build and install a wheel (recommended)

Install the build tool, build the package, then install the wheel from dist/. The pip commands below use the Tsinghua PyPI mirror.

pip install build --user -i https://pypi.tuna.tsinghua.edu.cn/simple
python -m build
python -m pip install dist/hastat-2.0.0-py3-none-any.whl --user -i https://pypi.tuna.tsinghua.edu.cn/simple

python -m build creates both the wheel and source archive in dist/.

Option B: Install the source checkout directly

Alternatively, install from the hastat directory:

python -m pip install . --user

Verify the installation

With --user, executables are installed in Python's user-level script directory, typically ~/.local/bin on Linux. Add that directory to your PATH if the hastat command is not found, then run:

hastat --help

Quick start

Try the supplied synthetic data from docs/examples:

cd docs/examples
hastat network -t gene.table.csv -m MST -o gene.mst.csv
hastat plot network --file gene.mst.csv --sample_hap gene.group.csv --sample_group populations.csv --show_node_label --show_edge_label -o network.png

Run hastat <command> --help for command help. The options below apply before the subcommand.

ArgumentDefaultDescription
--version—show program's version number and exit
--lognot setWrite log messages to a file; otherwise use the console.
02

Input files

Sample tables are CSV files with a header and one row per unique sample. IDs are read as text: 001, 1 and NA remain distinct. Leading and trailing whitespace is stripped. Phenotype values are numeric; missing values are excluded separately for each trait.

Input Format and purpose
VCF Indexed, compressed diploid VCF with sample genotypes. Keep its .tbi or .csi index beside it. Chromosome names must match the annotation and result tables.
GFF3 Gene annotation. The gene ID passed to the command must exist in the GFF.
Haplotype table chrom,pos,ref,alt,Hap1,Hap2,...; use view -t table to generate it. States are 0 (REF homozygote), 1 (heterozygote), 2 (ALT homozygote) and -1 (missing).
Haplotype assignments Two columns, samples,haplotypes; use view -t group. Each sample has one assignment.
Population assignments Two columns: sample ID and population label, for view --group and gene pop_file. Plotting bar, pie and network figures also accepts additional group columns selected with --group_index.
Phenotypes samples,Trait1,Trait2,...; missing tokens apply to measurements, not sample IDs.
Haplotype colors Headerless two-column CSV, such as Hap1,group1. These categories color haplotype rows, independently of population assignments.
Variant annotations pos,ann; chrom,pos,ann is recommended. Add optional label, and supply ref and alt together for allele-specific annotation.

Population files used by view must contain valid VCF sample IDs and nonempty groups. Network plots and allele-frequency tracks use samples with matching, nonempty selected group information.

Download the example inputs for complete file layouts.

03

view · Extract & summarize

Choose one target mode: a region, a gene ID, a gene list or comma-separated homologous gene IDs. Gene-based modes require --gff. Regions use 1-based inclusive coordinates.

Generate a haplotype table and sample assignments with the same region and filters:

hastat view -v gene.vcf.gz -r 1:1998001-2006000 -t table -o gene
hastat view -v gene.vcf.gz -r 1:1998001-2006000 -t group -o gene
Analysis type Result
geno Sample genotype matrix.
table Haplotype genotype-state table (.table.csv).
group Sample-to-haplotype assignments (.group.csv).
freq Sample counts by haplotype, optionally by population.
pi Per-base nucleotide diversity by population.
fst Weir–Cockerham Fst for every population pair.
tajima_d Tajima's D by population.
compare Haplotype comparison across two or more VCF files; supply corresponding --pop_names.

--het, --maf and --max_missing filter genotype-based outputs. For window statistics, --maf must remain 0 and --max_missing must remain 1; missing-data handling is defined by each statistic. These three filters are not supported for compare.

Window statistics

Set both the window size and step explicitly for regional scans. All three analyses require --group; Fst requires at least two groups.

hastat view -v gene.vcf.gz -r 1:1000001-3004000 -g populations.csv -t pi --size 50000 --step 50000 -o gene
hastat view -v gene.vcf.gz -r 1:1000001-3004000 -g populations.csv -t fst --size 50000 --step 50000 -o gene
hastat view -v gene.vcf.gz -r 1:1000001-3004000 -g populations.csv -t tajima_d --size 50000 --step 50000 -o gene
Statistic Interpretation and input handling Result columns
π Biallelic SNP diversity divided by the full window length. Assumes unrepresented eligible sites are invariant and all bases are callable. chrom,start,end,n_bases,counts,pi,groups
Fst A ratio of summed Weir–Cockerham variance components. Negative estimates are retained; sites lacking sufficient called samples are excluded. chrom,start,end,counts,fst,groups
Tajima's D Uses a fixed sample set within each population and biallelic SNPs with complete calls in that population. chrom,start,end,counts,tajima_d,groups

Windows have the requested size and are clipped at the region end. Undefined estimates remain NaN. Gene plotting displays the statistics from these CSVs.

stat · Haplotype–trait association

Compare numeric traits among haplotype groups. The minimum sample count is applied to finite observations separately for each trait.

hastat stat -g gene.group.csv -p phenotypes.csv -m TukeyHSD -s 10 -o association.csv
Method Overall test Pairwise comparisons
TukeyHSD Equal-variance one-way ANOVA. Tukey–Kramer comparisons, including unequal group sizes.
WelchBonferroni Welch's ANOVA. Pairwise Welch t-tests with Bonferroni-adjusted P values and simultaneous confidence intervals.

Both methods compare unadjusted trait values across independent haplotype groups. Select the method according to the assumptions of the data.

The CSV contains group counts, means and standard deviations, the mean difference (group2 − group1), overall-test P values, pairwise adjusted P values and confidence intervals. Inestimable comparisons retain missing values.

ArgumentDefaultDescription
-g
--group		RequiredA csv file containing the haplotype groups of samples with two columns: samples and haplotypes
-p
--pheno		RequiredA csv file containing the phenotype data of samples with two columns at least: samples and trait name
-s
--min_hap_size		10The minimum sample size for each haplotype
-a
--annotate		geneThe annotation of haplotypes
-m
--method		TukeyHSDTukeyHSD: equal-variance ANOVA + Tukey-Kramer; WelchBonferroni: Welch ANOVA + Welch t tests with Bonferroni correctionChoices: TukeyHSD, WelchBonferroni
--alpha0.05Family-wise significance level
-o
--out		not setThe output csv file name
05

network · Construct haplotype networks

Create a network from a haplotype table, then pass the result to hastat plot network.

hastat network -t gene.table.csv -m MST -o gene.mst.csv
hastat network -t gene.table.csv -m MSN -o gene.msn.csv
  • MST returns one minimum spanning tree with deterministic tie handling.
  • MSN includes all equal-weight alternatives that occur in any minimum spanning tree.

An edge weight counts unequal genotype states at loci complete across all input haplotypes. A locus containing missing calls is excluded for every pair.

CSV, TXT/edgelist, GEXF and GML are supported. CSV columns are source,target,weight,type. An isolated node has type=node and empty target and weight; it remains available for plotting. Use GEXF/GML when exporting isolated nodes to another application.

ArgumentDefaultDescription
-t
--hap_table		RequiredA CSV file containing the haplotype table (output from view -t table)
-m
--method		MSTNetwork construction method: MST (Minimum Spanning Tree) or MSN (Minimum Spanning Network)Choices: MST, MSN
-o
--out		networkThe output prefix for network analysis results

Bar & pie plots

Both plots join sample haplotype assignments to the selected population column. --group_index 1 selects the second CSV column; the first column contains sample IDs. --calc_percentage uses within-group fractions from 0 to 1.

hastat plot bar --sample_hap gene.group.csv --sample_group populations.csv --x_label Material --y_label Samples -o bar.png
hastat plot pie --sample_hap gene.group.csv --sample_group populations.csv -o pie.png

Phenotype box plots

Select the trait column with --phe_index (1 means the second CSV column). Add --comparisons once per displayed pair. Boxes can be drawn without comparisons.

hastat plot box --sample_hap gene.group.csv --sample_phe phenotypes.csv --method TukeyHSD --comparisons Hap1 Hap2 --comparisons Hap1 Hap4 --width 10 --height 5 -o box.png

t-test, welch and mannwhitneyu use Bonferroni adjustment across all eligible input-group pairs. TukeyHSD and WelchBonferroni use the same multiple-comparison methods as stat. The correction family includes every eligible pair; --comparisons selects the pairs to display. The plot's default minimum group size is 2, separately from the stat command's default of 10.

Network plots

Each call accepts one network file. Node area represents sample count; pie sectors represent population composition. Samples lacking the selected group are filtered out. Weighted Kamada–Kawai is the default layout.

hastat plot network --file gene.mst.csv --sample_hap gene.group.csv --sample_group populations.csv --show_node_label --show_edge_label --width 6 --height 6 -o network.png

Edge labels show numbers by default. Use --edge_label_symbol "|" for tick marks and --edge_label_size to adjust their size. Noninteger weights remain numeric.

Gene TOML reference

[default] contains shared settings. A section matching the selected gene, such as [GeneA], overrides only that gene's values. File paths are relative to the TOML file. Unknown parameters produce a warning and are skipped.

[default]
layout = "fixed"
bbox = [0.1, 0.1, 0.8, 0.8]
gene_color = "#24495D"
hap_count_show = true

[GeneA]
hap_file = "gene"
hap_color_file = "hap_colors.csv"

Coordinates, counts & tracks

Gene structure and window statistics

The gene view uses the requested flanks. Statistics tracks display all windows for that chromosome in their CSVs, so their genomic ranges can differ from the gene view.

shade_gene = true marks the annotated gene span, excluding its flanks. Pi values are displayed in units of 10⁻³; the source CSV retains the original per-base values. NaN values appear as gaps.

Haplotype counts and colors

hap_file = "gene" reads gene.table.csv and optionally uses gene.group.csv for sample counts. hap_color_file assigns haplotype color categories independently of sample populations.

Allele frequencies and LD

AF counts called allele copies: a heterozygote contributes one REF and one ALT; missing calls contribute neither. It uses vcf_file when supplied, or sample counts from the matching group file. pop_file provides population assignments. All matched samples contribute, including those in hidden haplotype rows.

LD is calculated from all VCF samples for the displayed variants.

Clustering

Haplotype clustering summarizes genotype-profile similarity using Hamming distances on common complete loci, with average linkage by default.
